# نظام «الوجيه» لإدارة العيادات والمراكز والمجمعات الطبية (Al Wagih Clinic & Hospital ERP)

نظام سحابي متكامل لإدارة العيادات والمراكز والمجمعات الطبية ومراكز الأشعة ومعامل التحاليل وفق نموذج تعدد العيادات والفروع (**Multi-Tenant Architecture**)، مبني بنسبة **100% على أدوات وتقنيات سحابية مجانية مدى الحياة** دون أي تكاليف تشغيل أو استضافة.

## 🚀 الأنظمة والوحدات التشغيلية الجديدة المضافة

### 1. 📺 نظام صالة الانتظار الذكية وشاشات التلفزيون والنداء الصوتي (Smart Waiting Queue & TV Display)
* **شاشة تلفزيون تفاعلية مخصصة (TV Screen):** مصممة لصالات الانتظار وشاشات الاستقبال الكبيرة بنظام داكن عالي التباين (Dark Mode).
* **نداء صوتي ثنائي ذكي (Web Audio Chime + Arabic SpeechSynthesis):** جرس تنبيه نغمي شبيه بالمطارات والمستشفيات العالمية + نداء ناطق باللغة العربية باسم العيادة ورقم الغرفة والتذكرة تلقائياً.
* **متابعة مباشرة عبر الهاتف (Mobile QR Tracking):** رمز QR يمسحه المريض بهاتفه لمتابعة دوره المباشر ومعرفة الحالات المتبقية أمامه.
* **إدارة الطابور والأولويات:** إصدار تذاكر ذكية للأدوار العادية والمستعجلة وحالات الطوارئ الحرجة (Emergency) وكبار الشخصيات (VIP) مع الربط اللحظي بين شاشات الأطباء والاستقبال والتلفزيون عبر LocalStorage/Supabase.

### 2. 👨‍⚕️ نظام نسب وعمولات وتسويات الأطباء (Doctor Commissions & Split Management)
* **لائحة عمولات مرنة لكل طبيب:** تخصيص نسب تعاقدية مستقلة لكل طبيب تشمل (نسبة كشوفات العيادة، نسبة العمليات والإجراءات، عمولة إحالات معمل التحاليل LIS، عمولة إحالات مركز الأشعة RIS، ونسبة استقطاع مستهلكات ومواد العمليات).
* **دفتر الأستاذ وحساب التسويات التلقائي (Settlements Ledger):** احتساب آلي وفوري لإجمالي الإيراد (Gross)، حصة المركز والمجمع الطبي، مستحقات الطبيب الإجمالية، استقطاعات التعقيم والمواد، وصافي المستحق للصرف (Net Payable).
* **كشف حساب رسمي معتمد للطباعة (Formal Financial Statement):** ترويسة رسمية للمجمع الطبي ببيانات الطبيب وجدول تفصيلي بالبنود وتوقيع المحاسب وخاتم الاعتماد.
* **سندات الصرف المالي وإغلاق الفترات:** توثيق طريقة الصرف (نقداً من الخزينة، تحويل بنكي، شيك معتمد) ورقم السند وإغلاق الفترة.
* **تصدير شيت Excel رسمي بترميز UTF-8 BOM:** تصدير تقرير تسويات الأطباء كاملاً بضغطة زر.

### 3. 🔬 نظام معمل التحاليل الطبية السحابي (LIS - Laboratory Information System)
* **كتالوج تحاليل إلكتروني متكامل:** تغطية تحاليل الدم الكاملة (CBC)، كيمياء الدم ووظائف الكبد والكلى، الدهون والسكر التراكمي (HbA1c)، الهرمونات والسيولة والبول والبراز.
* **إدارة أنابيب السحب والأكواد اللونية:** مطابقة ألوان وأنواع أنابيب السحب (EDTA Purple، Serum Gel Yellow، Sodium Citrate Blue...) وتوليد باركود حراري للعينة (Thermal Barcode).
* **رصد القيم الحرجة وإنذار الخطر (Panic Values / Critical Alerts):** تنبيه فوري أحمر عند تجاوز النتائج للحدود الخطرة.
* **طباعة النتائج بترويسة مخبرية رسمية:** تقرير معتمد إلكترونياً مع رمز QR للتحقق الرقمي وزر مراسلة المريض بالنتيجة فوراً عبر WhatsApp.

### 4. 🩻 نظام مركز الأشعة والتصوير التشخيصي (RIS - Radiology Information System)
* **دعم كافة أجهزة التصوير الطبي (Modalities):** الأشعة السينية الرقمية (X-Ray)، الرنين المغناطيسي (MRI)، الأشعة المقطعية (CT)، السونار والدوبلر (Ultrasound)، والماموجرام الرقمي (Mammography).
* **عارض صور إشعاعية رقمي (Medical DICOM/Scan Viewer):** عارض فحص تفاعلي يدعم عكس التباين (Invert Negative/Positive)، رفع التباين المجهري (High Contrast)، ومؤشرات بيانات الفحص (HUD).
* **قوالب كتابة تقارير الأشعة الجاهزة (Structured Reporting):** تقارير جاهزة لتقنيات الفحص (Technique) والموجودات (Findings) والانطباع النهائي (Impression).
* **تقارير أشعة رسمية قابلة للطباعة:** تقرير رسمي معتمد ببيانات الجهاز والطبيب وخاتم نقابة الأطباء ورمز التحقق الرقمي مع إرسال النتيجة بواتساب.

### 5. 📇 نظام إدارة علاقات المرضى المتكامل (Medical CRM Suite)
* **واتساب الطبي المباشر (Clinic WhatsApp Messenger):** قوالب جاهزة بنقرة واحدة لتذكير المواعيد، تعليمات الصيام والتحاليل، المتابعة بعد الكشف، واعتماد التأمين مع فتح تطبيق واتساب فوراً.
* **مركز الاتصال والكول سنتر (Call Center Studio):** تسجيل وتوثيق المكالمات الصادرة والواردة، نتائج المكالمات، نسب التحويل، ومواعيد إعادة الاتصال.
* **خدمة العملاء والشكاوى (Customer Service & Help Desk):** تذاكر الشكاوى والاستفسارات وقياس مؤشر رضا المرضى (CSAT).

### 6. 💼 بوابة المحاسب والرقابة المالية (Financial Controller & Audit Trail)
* **صلاحيات حصرية:** قصر صلاحية تعديل أو إلغاء الحركات المالية على المحاسب والمدير العام فقط.
* **سجل التدقيق الرقابي غير القابل للتعديل (Financial Audit Trail):** توثيق كل حركة مع التاريخ والمصرح وسبب التعديل أو الإلغاء.
* **إصدار المطالبات وفواتير الشركات:** استخراج مطالبات الشركات الآجلة بنسب الخصم والتحمل (Co-Pay) بصيغ Excel و PDF.

### 7. 🏢 نظام التعاقدات والشركات والتحصيل (Corporate Contracts & Co-Pay)
* **إدارة الشركات المتعاقدة:** إضافة وتعديل شركات التأمين، النقابات، والشركات الخاصة مع تحديد **نسبة الخصم المعتمدة لكل شركة (%)**.
* **تحديد طريقة الدفع في الحجز:** إمكانية الاختيار بين **نقدي (Cash)** أو **تعاقد شركة (Corporate / Insurance)**.
* **احتساب الخصم تلقائياً:** يقوم النظام آلياً بحساب قيمة الخصم بناءً على النسبة المحددة، وتوزيع المبلغ بين ما يسدده المريض نقداً بالخزينة وما يتم تسجيله كمطالبة آجلة على الشركة.

### 8. 📦 نظام جرد المخزن والمستلزمات الطبية (Medical Inventory & Stock)
* تتبع أرصدة الأدوية، المستلزمات الطبية، أدوات التعقيم، والوقاية.
* ضبط **حد إعادة الطلب الأدنى (Minimum Threshold)** مع ظهور شارات تحذيرية حمراء فورية للأصناف التي أوشكت على النفاد.
* تسجيل حركات الوارد والمنصرف وإمكانية زيادة الرصيد بضغطة زر وتصدير تقرير الجرد لملف Excel.

### 9. 👥 نظام الموارد البشرية والرواتب وبصمة الحضور (HR, Biometric & Penalties)
* إدارة ملفات الكادر الطبي، التمريض، موظفي الاستقبال، والإداريين.
* تتبع سجلات الحضور والانصراف بالبصمة البيومترية ومتابعة التأخيرات والغياب.
* سجل الجزاءات والمكافآت المعتمد من المدير المباشر.
* حساب مسير الرواتب الشهري آلياً وتصديره إلى Excel.

### 10. 💊 نظام الصيدلية الداخلية والروشتة الإلكترونية وفاحص التداخلات (Pharmacy & E-Prescription POS)
* **محطة صرف الروشتات اللحظية (E-Prescription POS):** استقبال فوري للروشتات الصادرة من غرف الكشف، فحص التغطية التأمينية والتحمل (Co-Pay)، والصرف السريع بضغطة زر مع خصم المخزون آلياً.
* **فاحص التداخلات الدوائية الإكلينيكي (Clinical Decision Support - CDS):** محرك إكلينيكي فوري لفحص التفاعلات الثنائية بين الأدوية (مثل Warfarin مع Aspirin، و Ciprofloxacin مع مضادات الحموضة الكالسيوم، و Concor) وتنبيه الطبيب والصيدلي فوراً بدرجة الخطورة.
* **إدارة دليل الأدوية وتواريخ الصلاحية (Drug Formulary & Expiry Tracker):** تتبع أرقام التشغيلات (Batch No) وتواريخ الانتهاء وتنبيهات ملونة للأدوية التي تنتهي صلاحيتها خلال أقل من 90 يوماً أو المنتهية.
* **محطة البيع المباشر (OTC Direct Sale Counter):** نقطة بيع مستقلة لمرتادي الصيدلية والجمهور بدون كشف طبي مع حساب الضريبة والخصومات.
* **طباعة استيكر الجرعة الدوائية (Patient Dosage Label):** توليد استيكر لاصق رسمي يوضع على علبة الدواء باسم المريض، الجرعة، التعليمات، وتاريخ الصرف.
* **تصدير شيتات Excel لصيدلية المجمع:** تصدير جرد المخزون وسجل المبيعات والمنصرف بترميز UTF-8 سليم.

### 11. 🦷 عيادة ومخطط الأسنان التفاعلي (Interactive Dental Odontogram FDI 11-48)
* **مخطط الأسنان الدائم الشامل (32 Permanent Teeth):** تصميم تفاعلي للفكين العلوي والسفلي بأرباعهما الأربعة وفق ترقيم FDI العالمي (11-48).
* **تحديد الحالات والأسطح المتأثرة:** تشخيص تسوس الأسنان (Caries)، الحشوات التجميلية (Composite)، علاج الجذور والعصب (Endo)، التركيبات والتيجان (Crowns/Zircon)، زراعة الأسنان (Implants)، والخلع (Extractions) مع تحديد الأسطح (O, M, D, B, L).
* **إصدار الخطة العلاجية وحساب التكلفة آلياً:** جدول مفصل بإجراءات الأسنان المعتمدة مع إمكانية طباعة الخطة وحفظها بسجل المريض وتصدير شيت Excel رسمي.

### 12. 🏥 وحدة جراحة اليوم الواحد وقائمة أمان منظمة الصحة العالمية (Day Surgery & WHO Safe Surgery)
* **قائمة التحقق الجراحية الآمنة لـ WHO (WHO Surgical Safety Checklist):** مطابقة مراحل الأمان الجراحي الثلاث بموجب معايير JCI: قبل التخدير (Sign In)، قبل الشق الجراحي (Time Out)، وقبل مغادرة العمليات (Sign Out).
* **إقرار وموافقة التدخل الجراحي المستنيرة (Surgical Consent Form):** نموذج إلكتروني رسمي معتمد بالترويسة وشرح التدخل والتخدير وتوقيع المريض والجراح وطباعته بضغطة زر.
* **إدارة غرف العمليات وأسرة الإفاقة (OR & Recovery Beds):** متابعة إشغال غرف العمليات الصغرى والمناظير وأسرة الإفاقة (PACU) وتوثيق تقرير الجراحة وإرشادات ما بعد العملية.

### 13. 🎫 تذكرة الانتظار الرقمية الذكية ومحفظة الروشتات للمريض (Live Queue Ticket & Digital Rx Wallet)
* **تتبع الدور الحي للمريض (Live Queue Position):** بطاقة تذكرة رقمية متقدمة في بوابة المريض تعرض رقم التذكرة، العيادة، الطبيب، وعدد المرضى المتبقين أمامه مع إشعار نبضي فوري عند حلول دوره "📢 دورك الآن!".
* **محفظة الروشتات الإلكترونية وصرف الأدوية (E-Prescriptions Wallet):** تمكين المريض من استعراض كافة روشتاته الطبية الموصوفة مع باركود دوائي رقمي يظهره لصيدلي المجمع للصرف الفوري بدون انتظار.
* **سجل الأسنان والعمليات الجراحية للمريض:** أرشيف إلكتروني موثق للمريض لمتابعة كافة علاجات الأسنان والعمليات الصغرى التي خضع لها مع تعليمات الغيار وفك الغرز.

### 14. 🏢 إدارة الفروع المتعددة والباقات الطبية الشاملة (Multi-Branch Operations & Preventive Wellness Bundles)
* **المحدد العام للفروع (Global Multi-Branch Switcher):** إمكانية تصفية المؤشرات والعيادات والحسابات بين الفروع أو عرض كافة الفروع مجمعة (فرع المعادي الرئيسي، فرع مدينة نصر، فرع المهندسين، فرع التجمع الخامس).
* **حركة التحويلات الطبية بين الفروع (Inter-Branch Referrals):** توثيق تحويلات المرضى بين الفروع لإجراء الفحوصات المتقدمة والرنين المغناطيسي والمناظير وعمليات اليوم الواحد.
* **باقات الفحص الطبي الشامل (Comprehensive Medical Packages):** باقات وقائية مجهزة (الفحص الشامل، رعاية السكري، صحة المرأة، الأسنان، الفحص الرياضي) مع نسب توفير تصل لـ 40% وحجز مباشر للمريض.
* **إرسال رسائل تأكيد الحجز بالواتساب يدوياً برغبة المستخدم:** إرسال تأكيد الحجز بالواتساب يتم بزر اختياري صريح في واجهة المريض والاستقبال وليس تلقائياً.

## 🛠️ الحزمة التقنية المجانية 100% (Free Tech Stack)

| الطبقة التقنية | الأداة المجانية | الوظيفة |
| :--- | :--- | :--- |
| **الواجهة الأمامية** | HTML5 + Tailwind CSS + Vanilla JS | واجهات فائقة السرعة تدعم الوضعين الداكن والفاتح (Dark/Light) واللغتين العربية والإنجليزية (RTL/LTR) |
| **الوسائط والنداء الصوتي** | Web Audio API + SpeechSynthesis | توليد نغمات جرس الانتظار الترددية وتوليف النداء العربي الصوتي لشاشات التلفزيون |
| **الرسوم البيانية** | Chart.js | عرض مؤشرات الأداء الحيوية (KPIs) ونسب الإشغال والإيرادات النقدية والشركات |
| **قاعدة البيانات & المصادقة** | Supabase (Free Tier) | قاعدة بيانات PostgreSQL + Supabase Auth + سياسات أمان الصفوف (RLS) |
| **تصدير التقارير والفواتير** | SheetJS (xlsx) + Native BOM Fallback | تصدير فواتير المطالبات، عمولات الأطباء، الورديات، الجرد، والتحاليل والأشعة والصيدلية إلى Excel بترميز UTF-8 سليم |
| **الاستضافة السحابية** | GitHub Pages / Vercel / Netlify | استضافة سحابية مجانية دائمة مع شهادة أمان SSL تلقائية ونشر مستمر CI/CD |
