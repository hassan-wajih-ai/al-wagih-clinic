# نظام «الوجيه» لإدارة العيادات (Al Wagih for Clinic Management)

نظام سحابي متكامل لإدارة العيادات والمراكز الطبية وفق نموذج تعدد العيادات والفروع (**Multi-Tenant Architecture**)، مبني بنسبة **100% على أدوات وتقنيات سحابية مجانية مدى الحياة** دون أي تكاليف تشغيل أو استضافة.

---

## 🏗️ الهيكل المعماري والأدوار الخمسة (Roles & Architecture)

1. **المدير العام (SuperAdmin):**
   * إدارة شبكة العيادات المسجلة بالكامل، تفعيل وتجميد الاشتراكات، ومتابعة مؤشرات نمو المنصة.
2. **مدير العيادة (Clinic Admin):**
   * إدارة فروع العيادة، الأطباء، موظفي الاستقبال، ومتابعة رسوم الكشوفات والإيرادات اليومية والأسبوعية.
3. **موظف الاستقبال (Receptionist):**
   * إدارة كشوفات الفرع اليومية، تسجيل المرضى، تتبع وتقفيل وردية العمل (8 ساعات) وتصدير تقرير الإغلاق المالي إلى **Excel**.
   * طباعة إيصالات الكشف الفورية للمرضى بصيغة **PDF**.
4. **الطبيب (Doctor):**
   * متابعة قائمة الانتظار الحية، استدعاء المرضى، توثيق التشخيص الطبي والروشتة العلاجية (Rx) وتحديث السجل الطبي.
5. **المريض (Patient):**
   * حساب موحد يتيح للمريض حجز موعد في أي عيادة وفرع، متابعة حالة الحجوزات، وتقييم الزيارات والخدمة الطبية (Feedback).

## 🛠️ الحزمة التقنية المجانية 100% (Free Tech Stack)

| الطبقة التقنية | الأداة المجانية | الوظيفة |
| :--- | :--- | :--- |
| **الواجهة الأمامية** | HTML5 + Tailwind CSS + Vanilla JS | واجهات فائقة السرعة وخفيفة تدعم اللغة العربية (RTL) ومتجاوبة مع الجوال |
| **الرسوم البيانية** | Chart.js | عرض مؤشرات الأداء الحيوية (KPIs) ومعدلات الحضور ونمو الإيرادات |
| **قاعدة البيانات & المصادقة** | Supabase (Free Tier) | قاعدة بيانات PostgreSQL + Supabase Auth + سياسات أمان الصفوف (RLS) |
| **تصدير التقارير** | SheetJS (xlsx) + jsPDF | تصدير تقارير الورديات والإيرادات إلى Excel وإيصالات الكشف PDF داخل المتصفح بدون سيرفر |
| **الاستضافة السحابية** | Vercel / Netlify / GitHub Pages | استضافة سحابية مجانية دائمة مع شهادة أمان SSL تلقائية ونشر مستمر CI/CD |

## 🚀 دليل التشغيل والنشر السحابي (5 دقائق)

### 1. إعداد قاعدة بيانات Supabase (مجانياً):
1. قم بإنشاء حساب ومشروع جديد على [Supabase](https://supabase.com).
2. افتح تبويب **SQL Editor**، وقم بنسخ وتشغيل الملفات التالية بالترتيب:
   * أولاً: انسخ وشغل محتوى ملف `supabase/schema.sql` (لبناء الجداول السبعة والمفاتيح).
   * ثانياً: انسخ وشغل محتوى ملف `supabase/rls_policies.sql` (لتفعيل سياسات عزل العيادات).
   * ثالثاً (اختياري): شغل `supabase/seed.sql` لإدخال بيانات تجريبية.
3. افتح ملف `js/config.js` في المشروع وضع رابط مشروعك ومفتاح `anonKey` الخاص بك.

### 2. النشر السحابي المجاني على Vercel:
1. ارفع المشروع على حسابك في **GitHub**.
2. افتح [Vercel](https://vercel.com) وسجل الدخول باستخدام GitHub.
3. اضغط **Add New Project** واختر مستودع المشروع.
4. اضغط **Deploy**.
5. خلال 30 ثانية سيكون موقعك متاحاً برابط مجاني دائم محمي بشهادة SSL تلقائية:
   `https://al-wagih-clinic.vercel.app`
