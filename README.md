# نظام «الوجيه» لإدارة العيادات والمراكز الطبية (Al Wagih for Clinic Management)

نظام سحابي متكامل لإدارة العيادات والمراكز الطبية وفق نموذج تعدد العيادات والفروع (**Multi-Tenant Architecture**)، مبني بنسبة **100% على أدوات وتقنيات سحابية مجانية مدى الحياة** دون أي تكاليف تشغيل أو استضافة.

---

## 🚀 الأنظمة والوحدات التشغيلية الجديدة المضافة

### 1. 🏢 نظام التعاقدات والشركات والتحصيل (Corporate Contracts & Insurance)
* **إدارة الشركات المتعاقدة:** إضافة وتعديل شركات التأمين، النقابات، والشركات الخاصة مع تحديد **نسبة الخصم المعتمدة لكل شركة (%)**.
* **تحديد طريقة الدفع في الحجز:** إمكانية الاختيار بين **نقدي (Cash)** أو **تعاقد شركة (Corporate / Insurance)**.
* **احتساب الخصم تلقائياً:** يقوم النظام آلياً بحساب قيمة الخصم بناءً على النسبة المحددة، وتوزيع المبلغ بين ما يسدده المريض نقداً بالخزينة وما يتم تسجيله كمطالبة آجلة على الشركة.
* **إصدار الفواتير والمطالبات:**
  * إصدار إيصالات وفواتير يومية فورية باسم المريض.
  * إصدار فواتير ومطالبات مجمعة بنهاية الشهر أو اليوم باسم الشركة المتعاقدة مع كشف حساب تفصيلي لكافة الحالات وتصديرها بصيغ **Excel (.xlsx)** و **PDF**.

### 2. 📦 نظام جرد المخزن والمستلزمات الطبية (Medical Inventory & Stock)
* تتبع أرصدة الأدوية، المستلزمات الطبية، أدوات التعقيم، والوقاية.
* ضبط **حد إعادة الطلب الأدنى (Minimum Threshold)** مع ظهور شارات تحذيرية حمراء فورية للأصناف التي أوشكت على النفاد.
* تسجيل حركات الوارد والمنصرف وإمكانية زيادة الرصيد بضغطة زر.
* تصدير تقرير جرد المخزن بالكامل إلى ملف Excel.

### 3. 👥 نظام الموارد البشرية والرواتب (HR & Payroll)
* إدارة ملفات الكادر الطبي، التمريض، موظفي الاستقبال، والإداريين.
* حساب مسير الرواتب الشهري آلياً: **(الراتب الأساسي + البدلات والمكافآت - الاستقطاعات والغياب = صافي الراتب المستحق)**.
* تصدير مسير الرواتب الشهري الرسمي إلى ملف Excel بنقرة واحدة.

## 🛠️ الحزمة التقنية المجانية 100% (Free Tech Stack)

| الطبقة التقنية | الأداة المجانية | الوظيفة |
| :--- | :--- | :--- |
| **الواجهة الأمامية** | HTML5 + Tailwind CSS + Vanilla JS | واجهات فائقة السرعة وخفيفة تدعم اللغة العربية (RTL) ومتجاوبة مع الجوال |
| **الرسوم البيانية** | Chart.js | عرض مؤشرات الأداء الحيوية (KPIs) ونسب الحضور والإيرادات النقدية والشركات |
| **قاعدة البيانات & المصادقة** | Supabase (Free Tier) | قاعدة بيانات PostgreSQL + Supabase Auth + سياسات أمان الصفوف (RLS) |
| **تصدير التقارير والفواتير** | SheetJS (xlsx) + jsPDF | تصدير فواتير المطالبات، الورديات، الجرد، ومسير الرواتب إلى Excel و PDF |
| **الاستضافة السحابية** | Vercel / Netlify / GitHub Pages | استضافة سحابية مجانية دائمة مع شهادة أمان SSL تلقائية ونشر مستمر CI/CD |
